# Tailoring Workflow Knowledge

This module outlines the production process for common Nigerian styles. Use this knowledge when generating production guides for the tailors.

## Women's Styles

### Corset Gown (Mermaid or Straight)
- **Required Materials:** Main fabric (e.g., Lace), lining (e.g., Satin), skin illusion net, bra cups, boning (rigilene or steel), interfacing (warding/stay), zipper, thread.
- **Cutting Sequence:** 
  1. Draft pattern (bodice with corset lines, skirt). 
  2. Cut main fabric, lining, and interfacing. 
  3. Cut illusion net for yoke/sleeves if required.
- **Sewing Sequence:** 
  1. Interface bodice pieces. 
  2. Sew corset channels and insert boning. 
  3. Attach bra cups. 
  4. Sew skirt panels (front and back). 
  5. Join bodice to skirt. 
  6. Attach lining. 
  7. Insert zipper. 
  8. Attach sleeves/yoke.
- **Fitting Stages:** 
  - *1st Fitting:* Bodice fit (corset tightness, cup placement).
  - *2nd Fitting:* Skirt fit (hips, length), zipper test.
- **Finishing Process:** Hand-beading/stoning, hemming, pressing, clipping loose threads.

### Boubou / Kaftan
- **Required Materials:** Flowy fabric (Chiffon, Silk, Crepe, or Brocade), matching thread, stones/embroidery threads (if applicable).
- **Cutting Sequence:** 
  1. Cut front and back panels (usually cut together on fold). 
  2. Cut neckline facing.
- **Sewing Sequence:** 
  1. Neaten neckline with facing. 
  2. Do any required embroidery/stoning on the neckline or body. 
  3. Join shoulders. 
  4. Sew side seams (leaving required width for sleeves). 
  5. Hem bottom and sleeve edges.
- **Fitting Stages:** 
  - *1st Fitting:* Length check, neckline depth check.
- **Finishing Process:** Ironing, attaching any inner belts for shape, final stoning.

## Men's Styles

### Agbada (3-Piece)
- **Required Materials:** Main fabric (Aso-Oke, Brocade, or high-quality Wool/Cotton), lining for the inner buba, embroidery thread, trouser zipper/elastic, interfacing for necklines.
- **Cutting Sequence:** 
  1. *Sokoto (Trousers):* Cut front and back legs, waistband. 
  2. *Buba (Inner shirt):* Cut front, back, sleeves. 
  3. *Agbada (Outer robe):* Cut wide body panels, neck opening.
- **Sewing Sequence:** 
  1. *Embroidery:* Send Buba and Agbada neck panels for embroidery BEFORE joining. 
  2. *Trousers:* Sew legs, insert crotch, attach waistband/zipper, hem. 
  3. *Buba:* Join shoulders, attach sleeves, sew side seams, finish neckline. 
  4. *Agbada:* Join shoulders, hem large armholes, fold and sew side tacking points.
- **Fitting Stages:** 
  - *1st Fitting:* Trouser waist and length, Buba chest and sleeve length.
  - *2nd Fitting:* Agbada drape and length over the inner pieces.
- **Finishing Process:** Heavy pressing (especially embroidery), starching (if Aso-Oke/Cotton).

### Senator Suit
- **Required Materials:** Main fabric (Cashmere, Wool, Linen, thick Cotton), matching thread, buttons/snaps, zipper for trousers, interfacing for collar/placket.
- **Cutting Sequence:** 
  1. *Top:* Cut front, back, sleeves, front placket/design panels. 
  2. *Trousers:* Cut front and back legs, waistband, pockets.
- **Sewing Sequence:** 
  1. *Top:* Prepare front design/placket. Join shoulders, attach sleeves, side seams. Finish neckline (often a small band collar). 
  2. *Trousers:* Sew pockets, join legs, insert zipper, attach waistband.
- **Fitting Stages:** 
  - *1st Fitting:* Trouser fit (waist, thigh, length), Top fit (chest, shoulder width, sleeve length).
- **Finishing Process:** Attach buttons/snaps, press sharp creases on trousers, iron top flat.
